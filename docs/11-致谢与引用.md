# 致谢与引用的开源项目

codex2dsh 无运行时依赖（`dependencies` 为空），以下项目以**可选协同 / 目标平台 / 格式契约**方式被引用，特此致谢。感谢每一位维护者与贡献者。

## 协作与委托

| 项目 | 链接 | 用途 | 致谢 |
| --- | --- | --- | --- |
| **dsh-chat-import**（Nwflower） | https://github.com/Nwflower/dsh-chat-import | 会话历史导入委托（`import_chat` 分发器，`format: 'codex'`；v0.8.0 前为 `import_codex` 单源工具） | 感谢维护者主动发出 v0.8.0 兼容性预警（[codex2dsh#1](https://github.com/BigBlueBaby/codex2dsh/issues/1)）并保持协作链：`session/imported` 标记 `data.tool='codex'` 不变，标题回填与工作区归组不受重构影响。 |
| **dsh-mnemon**（omdsh-dev） | https://github.com/omdsh-dev/dsh-mnemon | Codex 记忆导入目标引擎（全局记忆，storageScope=global → `~/.mnemon`）：Runtime 每轮注入 + Documents 全文检索 + 可插拔 Memory Spaces | 感谢其三层记忆架构与稳定的存储格式（`runtime/memories.json` 投影、`documents/index.json` + frontmatter 文档），使 `codex2dsh_import_memory` 可以无损导入迁移的 Codex 记忆。 |

## 目标平台与格式契约

| 项目 | 链接 | 用途 |
| --- | --- | --- |
| **DeepSeek Harness（@deepseek-ai/dsh）** | https://github.com/deepseek-ai/deepseek-harness | 插件宿主平台：Cordis 组合、profile/bundle、工具注册、会话持久化 |
| **@deepseek-ai/dsh-mcp-client** | https://github.com/deepseek-ai/deepseek-harness（monorepo 内） | MCP 服务器注册契约：每台服务器一个插件实例（`serverName` / `transport` / `command` / `args`），工具名 `mcp__<serverName>__<rawName>` |

## 致谢说明

- **Nwflower（dsh-chat-import 维护者）**：主动提前预警工具面收敛（import_codex → import_chat），并在发布后实测确认影响点，降低了本插件的适配成本。再次感谢！
- **omdsh-dev（dsh-mnemon 维护者）**：为 DSH 提供了一流的全局记忆控制面，其格式文档化程度高，是记忆迁移落地的理想目标。
- 以上项目均为**可选协同**：未安装时 codex2dsh 给出安装指引而非报错；安装后自动委托/导入。

> 如果本插件的使用或文档中涉及其他开源成果而遗漏致谢，欢迎提 issue 补充。

# 09 · 安全边界

> 状态：**基线文档** · 适用：全部工具与 CLI · 关联：[03-映射规范 §0](03-映射规范.md#0-总则)

## 1. 核心承诺（对用户）

1. **源码只读**：`~/.codex/**` 任何文件永不写入、永不移动、永不删除。
2. **秘密不落盘**：`auth.json`、`.codex-global-state.json`、`chrome-native-hosts*.json` 的内容**不读取**（只报告存在）。
3. **密钥必脱敏**：一切输出（镜像片段、建议、报告、台账）中的 `password/token/key/secret/bearer` 值替换为 `****`。
4. **默认预览**：任何写盘动作默认 dry-run；`apply:true` 才写。
5. **profile 不自动改**：`cordis.patch.yml`、`settings.yaml`、profile `package.json` 只产出"待合并片段"，由用户人工审阅合并。
6. **幂等不覆盖**：目标已存在且内容不同时拒绝覆盖（需 `force`），防覆盖人工修改。

## 2. 脱敏规则（`lib/report.mjs` 的 `maskSecrets`）

- 触发词（大小写不敏感）：`password`、`passwd`、`pwd`、`token`、`secret`、`api[_-]?key`、`bearer`、`credential`、`authorization`、`cookie`；
- 判定范围：TOML 键名、`--flag=value`/`--flag value` 参数、`KEY=value` 环境变量、JSON 键；
- 替换为 `****`（保留键名与结构）；同时输出建议行：`建议将 <来源> 改为环境变量引用（如 ${CODEX2DSH_<NAME>_<KEY>}）`；
- 例外：值为空、`PROXY_MANAGED` 等占位符、`${...}` 变量引用（原样保留，它们不是秘密本体）；
- **绝不把脱敏前的值写入任何输出**（含日志）。

## 3. 网络边界

- 本项目**无任何出网请求**（不调用远程服务、不遥测、不上传）；
- MCP 服务器的启动由 DSH 运行时执行——迁移本身不启动任何 MCP 服务器；
- 若未来接入市场目录（M5 可选），仅按 dsh-community-market 契约访问用户显式添加的来源 manifest（HTTPS），且不执行来源下发的任何命令/脚本。

## 4. 权限与审计

- 工具面最小化：只申请 `fs`、`tools`（必需）与可选的 `webServer`/`commands`/`settings`；
- 每次迁移写台账（`$DSH_HOME/codex2dsh/ledger.json`）：`ts / tool / source / sourceFingerprint(sha256) / target / status / maskedCount`，用户可 `codex2dsh ledger` 审计；
- 报告与台账中出现 `skipped(secret)` 表示"发现敏感资产但未触碰"，可放心复查。

## 5. 仓库卫生（开发者）

- 禁止提交真实 `config.toml`/`AGENTS.md`/夹具外的任何真实用户数据；
- fixture 必须脱敏（示例值用 `example`/`****`/`127.0.0.1` 等）；CI 检查 fixture 不含敏感词表（`password` 等触发词 + 内网 IP 段 `10.` / `192.168.`）；
- `.gitignore` 已排除 `migrate-output/`、`*.migration.json`、`.env*`；
- 密钥类问题走 [SECURITY.md](../../SECURITY.md) 的私密报告渠道（发布后配置）。

## 6. 已知风险与缓解

| 风险 | 缓解 |
| --- | --- |
| 用户在审阅 MCP 片段时把 `****` 替换回真实密码并入库 | 文档与报告持续提示；镜像文件生成时头部注释写明"含敏感值，勿提交仓库" |
| 技能脚本本身含恶意/内网路径 | 迁移原样保留但报告中列出脚本清单与路径，提示人工审阅后再启用 |
| TOML 解析偏差导致漏迁移/误迁移 | 解析器容错降级 + 报告 `parse-partial` 项 + fixture 锁定 + L4 演练比对 |
| 委托 import_codex 时的权限放大 | 委托仅传本项目参数（path/budget/restamp 等），不注入额外权限；其结果与台账记录 |

## 7. 报告与处置

任何安全相关缺陷：**不要在 Issue 中贴真实配置/密钥**；发布后按 [SECURITY.md](../../SECURITY.md) 私密披露（临时：邮件/私信项目维护者，正文脱敏）。

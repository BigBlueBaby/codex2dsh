## 1. 模块划分（`lib/`）

| 模块 | 职责 | 依赖 | 里程碑 |
| --- | --- | --- | --- |
| `lib/config.mjs` | Codex `config.toml` 轻量解析：提取 `model/model_provider/model_reasoning_effort/mcp_servers/model_providers/projects/features/memories/windows.sandbox`；TOML 数组/内联表解析；解析失败降级（逐行容错 + 报告未解析节） | 无 | M1 |
| `lib/yaml.mjs` | 极简 YAML 渲染（键值/数组/缩进/引号），供镜像片段与建议片段输出 | 无 | M1 |

| `lib/ledger.mjs` | 台账 `$DSH_HOME/codex2dsh/ledger.json`：append、查询、幂等判定辅助 | — | M1 |
| `lib/report.mjs` | 统一报告结构（见映射规范 §10）、`maskSecrets()` 脱敏、`sha256()` 指纹 | — | M1 |
| `lib/doctor.mjs` | 体检：逐资产状态（已迁移/待迁移/不可迁移/密钥残留）、汇总表 | 全部 | M3 |
| `lib/delegate.mjs` | 会话委托：探测 `import_codex`、调用、结果回填台账；未安装时输出安装指引 | — | M4 |
| `lib/tools.mjs` | 工具注册：`TOOL_SPECS` 表 + `registerTools(ctx, ledgerDir)`；每个 spec 含 `toolName/description/parameters/execute` | 全部 | M1→M4 逐增 |
| `lib/panel.mjs` | （M4）`POST /codex2dsh/*` 面板路由：preview / apply / doctor / ledger | tools 同逻辑 | M4 |

**分层规则**：`lib/` 中除 `tools.mjs / panel.mjs / command.mjs / index.mjs` 外都是**纯函数**（不 import `@deepseek-ai/*`，全部可独立单测）；工具层只做"参数 → 纯函数 → 报告/落盘"编排。

## 3. 关键数据流

### 3.1 MCP 镜像

```
config.toml ──lib/config.mjs──► ParsedConfig
    └─ mcp_servers ──lib/mcp.mjs──► PlanItem[] {name,type,command,args,env,timeout,masked:[...]}
        ├─ 运行时排除（默认）
        ├─ 密钥脱敏（maskSecrets 逐字段）
        └─ lib/yaml.mjs ──► mcp-mirror.cordis.yml（apply:true）
                 └─ 幂等：sha256 比对旧文件（同→skipped；异→需 force）
                 └─ 台账 append
```

### 3.2 技能转换

```
skills/<name>/
  ├─ SKILL.md ──判定──► 可迁移（用户/第三方）
  │     ├─ frontmatter: 追加 kind:dsh / source:codex（已有 kind:dsh → skipped）
  │     ├─ 冲突：目标存在同名 → <name>-codex
  │     └─ 写盘 + 台账
  └─ scripts/ ──► 整体复制（冲突目录合并提示）
  ├─ .system|codex-primary-runtime|openai-bundled ──► skipped(runtime/marketplace)
  └─ 缺 SKILL.md ──► invalid（fixFrontmatter 可补全）
```

### 3.3 委托会话导入

```
sessions/** ──统计──► 规模报告
        └─ 检测 tools 中 import_codex
              ├─ 有 ──► 调用（preview 透传）──► 台账记录
              └─ 无 ──► 返回安装指引（dsh plugin add dsh-chat-import）
```

## 4. 错误处理约定

| 场景 | 行为 |
| --- | --- |
| `config.toml` 不存在 / 不可读 | 返回 `ok:false` + 明确原因与排查步骤；**不抛未捕获异常** |
| TOML 局部语法不支持（多行数组等） | 该节标记 `parse-partial`，值交人工确认，不静默丢弃 |
| 目标路径不可写 | `ok:false` + 提示权限/路径，不动源 |
| 写入中途失败 | 先写临时文件再 rename（原子写）；失败清理临时文件 |
| 超长会话委托 | 透传 `budget` 参数给 import_codex（上下文预算保护） |
| 未知技能格式 | `invalid` 报告，不猜测 |
| 密钥文件被要求读取 | 一律拒绝并报告（`skipped(secret)`） |

## 5. 幂等与并发

- **幂等键**：`(sourcePath + sha256(source) + target)` 记入台账；重复迁移先查台账。
- **force 语义**：`force:true` 时以新目标名（如 `-codex-2`）另存，旧资产不动。
- **并发**：写盘用"临时文件 + rename"；台账 append 用单文件追加锁（`open('a')` 天然原子追加）。

## 6. 目录与文件命名（遵循用户全局规则）

- 文档产物（`docs/`、迁移输出说明）使用**中文文件名**；
- 代码/脚本/夹具使用英文名（工程惯例），注释使用中文；
- 迁移产物输出目录默认 `$DSH_HOME/codex2dsh/`，可在参数中覆盖。

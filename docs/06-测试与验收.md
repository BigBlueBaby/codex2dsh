# 06 · 测试与验收

> 状态：**基线文档** · 关联：[05-实现方案](05-实现方案.md) · [07-发布与分享](07-发布与分享.md)

## 1. 测试分层

```
L1 单元测试（node:test）        —— lib/ 纯函数，无 host 依赖
L2 工具面测试（fake ctx）        —— tools.mjs 注册逻辑，用记录型 ctx 桩
L3 集成测试（真实 dsh headless） —— dsh 进程加载插件 + 调用工具（CI 可选）
L4 真实迁移演练（人工手册）      —— 用户本机完整流程
```

## 2. L1 单元测试（`test/*.test.mjs`）

| 测试文件 | 覆盖 |
| --- | --- |
| `config.test.mjs` | TOML 解析：`[mcp_servers.*]` 全字段、单双引号数组、内联 env、`startup_timeout_sec`、多节混杂、损坏 TOML 降级 |
| `mcp.test.mjs` | 计划生成：运行时排除规则（名称/路径/env 特征）、密钥脱敏逐字段、`renderMcpPlan` 输出与 fixture 快照一致、幂等比对 |
| `skills.test.mjs` | 判定（`.system`/marketplace/用户）、frontmatter 追加 `kind/source`、冲突后缀、内容相同 skipped、`scripts/` 复制、缺 frontmatter 补全 |
| `instructions.test.mjs` | 来源注释块、AGENTS.md+instructions.md 并存、项目级建议生成 |
| `memory.test.mjs` | 可读资产解析、sqlite 探测降级路径 |
| `settings.test.mjs` | 建议结构（agent-default-model/permission/projects）、脱敏 |
| `yaml.test.mjs` | 渲染器：引号/缩进/数组/特殊字符 |
| `report.test.mjs` | 统一报告结构、maskSecrets 正则覆盖（password/token/key/secret/bearer 各种形态） |
| `ledger.test.mjs` | 台账 append/查询/幂等键 |

**约定**：fixture 一律用 `test/fixtures/` 脱敏样例；覆盖率目标 line ≥ 75%（`node --test --experimental-test-coverage`，与生态参考插件同门槛）。

## 3. L2 工具面测试

- `tools.test.mjs`：用记录型 fake ctx（`{ tools: { register: spy } }`）断言注册的工具名/参数 schema 与 `index.d.ts` 的 ToolSurface 一致；
- 每个工具在 fake ctx 上跑 `execute`：dry-run 不落盘、apply 落盘、幂等第二次 skipped、force 新副本。

## 4. L3 集成冒烟（真实 dsh headless）

在 CI（Linux）与本机各跑一次：

```bash
dsh --profile smoke -y  # 或等价 headless 方式
```

冒烟断言：

1. 插件加载无异常（`apply` 完成，日志无 error）；
2. `migrate_codex_preview` 在**脱敏夹具目录**（临时 CODEX_HOME）上输出完整清单；
3. `migrate_codex_skills --apply` 后 `$DSH_AGENTS_HOME/skills/` 出现目标技能；
4. 卸载（移除 insert 行）后重启正常。

> CI 冒烟用临时 `CODEX_HOME`/`DSH_HOME`/`DSH_AGENTS_HOME` 环境变量指向夹具目录，**绝不触碰真实用户目录**。

## 5. L4 真实迁移演练手册（发布前必做）

在真实 `~/.codex`（本机）执行，并核对：

| 步骤 | 预期 |
| --- | --- |
| 1. `migrate_codex_preview` | 列出全部 MCP/技能/指令/记忆/会话，规模合理 |
| 2. `migrate_codex_mcp`（dry-run） | 输出片段中密码为 `****`，运行时服务器被排除 |
| 3. 审阅后人工合并 `mcp-mirror.cordis.yml` 进 profile | profile 重启后 DSH 能连上迁移的 MCP（抽测 1 个服务器） |
| 4. `migrate_codex_skills --apply` | 技能出现在 DSH 技能列表，会话内可调用 |
| 5. `migrate_codex_instructions --apply` | 新会话注入全局规则（抽查首屏提示） |
| 6. `migrate_codex_memory --apply` | 记忆资产可检索 |
| 7. `migrate_codex_sessions` | 委托 import_chat 成功导入，可续聊 |
| 8. `codex2dsh_doctor` | 全部绿色，无密钥残留警告 |
| 9. 重复执行 2/4 | 全部 `skipped`（幂等） |
| 10. 卸载插件 | 已迁移资产完好，无自动删除 |

**验收矩阵**（发布 gate）：

| 项 | 标准 |
| --- | --- |
| 单测 | `npm test` 全绿，line ≥ 75% |
| lint | eslint 无 error |
| 冒烟 | L3 通过 |
| 演练 | L4 十步全部符合预期 |
| 文档 | 本文档状态行同步，CHANGELOG 更新 |

## 6. CI（`.github/workflows/ci.yml`）

```yaml
name: CI
on: [push, pull_request]
jobs:
  test:
    strategy:
      matrix:
        os: [ubuntu-latest, windows-latest]
        node: [22, 24]
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with: { node-version: "${{ matrix.node }}" }
      - run: npm ci || npm install      # 无 lockfile 时回退
      - run: npm test
      - run: npm run lint
  smoke:   # 可选：真实 dsh headless 冒烟（ubuntu）
    needs: test
    steps:
      - run: npx dsh@latest plugin ... / 或按 dsh 发布方式安装
      - run: 冒烟脚本（见 §4）
```

## 7. 测试数据卫生

- 所有 fixture 为**脱敏虚构数据**（示例密码一律 `****` 或 `example`）；
- 禁止把真实 `config.toml`（含任何内网地址/账号）提交入库；
- 若需复现真实结构，先跑 `lib/report.mjs` 的脱敏器再落 fixture（CI 加"fixture 无敏感词"检查，敏感词表：`password/token/secret/192.168./10.\d+.\d+` 等，见 [09-安全边界](09-安全边界.md)）。

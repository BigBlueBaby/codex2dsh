# 03 · 映射规范（Codex → DSH 逐项映射）

> 状态：**基线文档**（字段级对照；实现必须与此一致，差异以本文件为准修订） · 关联：[02-Codex配置解剖](02-Codex配置解剖.md) · [04-插件API参考](04-插件API参考.md)

## 0. 总则

| # | 原则 | 含义 |
| --- | --- | --- |
| R0 | 源码只读 | `~/.codex/**` 只读，任何工具不写源侧 |
| R1 | 默认预览 | 所有写盘操作 `apply:false` 时为 dry-run，返回将写入的完整内容与路径 |
| R2 | 密钥脱敏 | 输出中的 `password/token/key/secret/bearer` 一律 `****`，并给出"改用环境变量"建议 |
| R3 | 幂等 | 内容相同 → 跳过（报告 `skipped`）；内容变化 → 增量更新；`force:true` → 新副本 |
| R4 | 人工闸门 | 修改 profile（MCP / 模型 / 权限）只产出"待合并片段"，绝不自动改 `cordis.patch.yml` / `settings.yaml` |
| R5 | 台账 | 每次迁移记录到 `$DSH_HOME/codex2dsh/ledger.json`（来源路径、指纹、目标、时间、结果） |

## 3. MCP 服务器镜像（核心能力）

### 3.1 解析（`lib/config.mjs` + `lib/mcp.mjs`）

从 `config.toml` 提取 `[mcp_servers.<name>]`，归一化为：

```js
{ source: 'codex', name, type, command, args: [], env: {}, startupTimeoutSec }
```

- `type`：`stdio`（默认）| `sse` | `http`；缺失视为 `stdio`。
- `args`：支持 `["a", 'b']` 单双引号数组（复用 dsh-chat-import `parseTomlArray` 语义）。
- `env`：支持 `{ KEY = "value" }` 内联表；含 `${VAR}` 的值原样保留（DSH 侧展开）。
- `startup_timeout_sec`：数值保留。

### 3.2 运行时服务器排除规则（重要）

以下服务器**默认排除**并报告（`excludeRuntime:true` 参数可关）：

- 名称匹配：`node_repl`、`computer_use`、`browser`、`chrome`；
- 命令路径含：`Codex\runtimes`、`openai-bundled`、`codex-computer-use`、`node_repl.exe`；
- `env` 中含 `CODEX_CLI_PATH` 或 `SKY_CUA_NATIVE_PIPE*` 的服务器。

### 3.3 密钥策略（对每个服务器逐字段判定）

| 字段 | 判定 | 处理 |
| --- | --- | --- |
| `args` / `env` 中匹配 `(?i)pass(word)?\|token\|secret\|key\|bearer` | 敏感 | **默认按原样迁移**（用户明示需求，迁移后直接可用）；`maskSecrets:true` 时替换为 `****`；无论哪种模式，报告都给出敏感值计数 |
| `env.PATH` 含 `${PATH}` | 透传 | 原样保留 |
| 其他 | 普通 | 原样保留 |

> ⚠️ 原样迁移意味着镜像片段含真实密钥：请勿把 `mcp-mirror.cordis.yml` 等产物提交到公开仓库（见 [09-安全边界](09-安全边界.md)）。

### 3.3b 选择性迁移（include / exclude）

- `include: [name]` 只迁移列出的服务器（精确名）；缺省 = 全部。
- `exclude: [name]` 排除列出的服务器；支持 `*` 前缀通配（如 `exclude: ["kingbase-*"]` 排除全部金仓库）。
- 运行时服务器排除规则（§3.2）始终优先。
- UI 中每个服务器有勾选框，默认全选。

### 3.3c 本地工具目录随迁（mcp-toolbox 等）

- 检测：服务器 `command/args/env` 中引用 `~/.codex/tools/<name>` 路径 → 视为本地工具（如 `mcp-toolbox` 的 `toolbox.exe` + `tools.yaml`）。
- 迁移：`migrateTools`（默认 true）时把整个工具目录复制到 `$DSH_HOME/codex2dsh/tools/<name>`；目标已存在则跳过（幂等）。
- 路径重写：镜像片段中 `command/args/env` 里的 Codex 侧路径**同步改写**为目标路径，保证镜像开箱即用。
- 报告类别：`kind: "tool"`。

### 3.4 输出格式（`mcp-mirror.cordis.yml`）

生成**可人工审阅合并**的 DSH MCP client 配置片段。DSH 生态的 MCP client 插件（`dsh-mcp-client`）以 Cordis 组合条目启用，因此镜像文件顶层结构与 `cordis.patch.yml` 兼容：

```yaml
# codex2dsh 生成的 MCP 镜像（人工审阅后合并进 profile 的 cordis.patch.yml / cordis.yml）
# 来源: C:\Users\<user>\.codex\config.toml · 幂等键: sha256(config.toml)
# ⚠️ 默认密钥原样迁移；本文件含真实凭据，请勿提交公开仓库
- insert:
    - id: dsh-mcp-client
      name: dsh-mcp-client
      config:
        servers:
          google-mcp-toolbox:
            type: stdio
            command: 'C:\Users\<user>\.dsh\codex2dsh\tools\mcp-toolbox\toolbox.exe'   # ← 工具目录已随迁并重写路径
            args: ["--config", 'C:\...\tools.yaml', "--stdio", "--disable-reload"]
            startupTimeoutSec: 120
          kingbase-gchgz-dsj-dev:
            type: stdio
            command: "npx"
            args: ["universal-db-mcp", "--permission-mode", "readwrite",
                   "--type", "kingbase", "--host", "192.168.10.99", "--port", "54322",
                   "--user", "system", "--password", "<原样保留>", "--database", "dsj"]   # ← 默认原样迁移
            startupTimeoutSec: 120
```

> 契约说明：dsh-community-market 的安装器对 "DSH bundle patch" 的校验是"安装包内存在且不越界"，`dsh-mcp-client` 的服务器配置形态以该插件发布文档为准；本规范把"服务器配置块"作为**独立 YAML 片段**生成，合并时可整体放入 `config:` 下，兼容性由 fixture 单测锁定。

### 3.5 幂等

- 目标文件已存在且内容相同 → `skipped`；
- 已存在但内容不同 → 默认**不覆盖**（提示 `--force` / `force:true`），防止覆盖人工修改过的合并结果。

## 4. 技能转换（核心能力）

### 4.1 判定哪些技能可迁移

| 条件 | 处理 |
| --- | --- |
| 目录名以 `.` 开头（`.system` 等） | 跳过（运行时） |
| 目录名含 `codex-primary-runtime` / `openai-bundled` / marketplace 分发标记 | 跳过（报告原因） |
| `SKILL.md` 缺失 | 报告 `invalid`（可选 `--fix-frontmatter` 补全，见 4.4） |
| 未选中（`include` / `exclude`） | 跳过（`exclude` 支持 `*` 前缀通配，如 `exclude: ["ccpanes-*"]`） |
| 其余（用户/第三方安装） | ✅ 迁移 |

**选择性迁移**：`include`/`exclude` 参数（精确名 + `*` 前缀通配）过滤候选技能；UI 中每个技能有勾选框，默认全选，支持「按前缀排除」（输入逗号分隔的前缀批量取消勾选，如 `ccpanes-`）。

### 4.2 SKILL.md 转换规则

```markdown
# Codex 源（frontmatter: name/description）
---
name: find-skills
description: 检索已安装技能并给出使用方法。
---

# DSH 目标
---
name: find-skills
description: 检索已安装技能并给出使用方法。   # 保留原文
kind: dsh                                    # ★ 标记已适配 DSH
source: codex                                # ★ 来源标记（供审计/幂等）
---
（正文原样保留，不做摘要）
```

- **正文原样保留**（Codex 与 DSH 的技能正文均为 Markdown 指令文本，可直接复用）；
- `kind: dsh` 标记用于：已带该标记的技能**不重复导入**（幂等判定）；`scripts/` 目录整体复制；
- 冲突：`$DSH_AGENTS_HOME/skills/` 已存在同名 → 新目标加 `-codex` 后缀（`find-skills-codex`），报告消歧；
- 内容完全相同 → `skipped`。

### 4.3 脚本目录

`SKILL.md` 引用的 `scripts/*` 一并复制；若脚本含 shebang/路径，报告差异（如 `codex exec` 相关脚本提示人工适配）。

### 4.4 缺 frontmatter 的补全

技能目录存在但 `SKILL.md` 缺 `name/description`（罕见）：`--fix-frontmatter` 时用目录名补 `name`、用首段文本生成 `description`，并在报告标注 `auto-filled`。

## 5. 全局指令转换

| 源 | 目标 | 规则 |
| --- | --- | --- |
| `~/.codex/AGENTS.md` | `$DSH_AGENTS_HOME/instructions/global.md` | 原文完整保留；文件头追加来源注释块（`<!-- codex2dsh: from ~/.codex/AGENTS.md ... -->`），不改变正文 |
| `~/.codex/instructions.md`（若存在） | 同上（`global-instructions.md`） | 与 AGENTS.md 并存，报告两者优先级差异，请用户决定合并方式 |
| 项目级 `AGENTS.md`（扫描 Codex 项目信任列表） | 报告 + 生成项目级指令挂载建议 | 不自动写盘（R4） |

## 6. 记忆迁移

| 源 | 处理 |
| --- | --- |
| `memories/*.md` 等可读文件 | 转换条目为 DSH 记忆资产（`$DSH_HOME/memories/codex/` 或 DSH 记忆目录约定），每条带来源与时间戳 |
| `memories_1.sqlite` | 只读探测：可读 → 提取条目；不可读/版本不明 → 报告存在与体积，引导用户自查，**不猜测解析** |
| `[memories]` 开关 | 关闭时：报告"Codex 记忆未开启，跳过" |

## 7. 模型 / Provider / 权限（只读建议）

生成 `settings-suggest.cordis.yml` 或直接返回结构化建议（`migrate_codex_config` 的返回值），示例：

```jsonc
{
  "agentDefaultModel": {
    "suggested": { "provider": "deepseek", "model": "deepseek-v4-flash", "reasoningEffort": "max" },
    "note": "源 provider 'custom' 的 base_url 为 http://127.0.0.1:15721/v1；DSH 侧请先在 settings.yaml 配置同名 provider 后采用本建议。"
  },
  "permission": {
    "suggestedPreset": "danger-full-access",
    "note": "源 [windows].sandbox='elevated' 与 DSH permission.defaultPreset 语义不完全一致，请按需选择。"
  },
  "projects": [ { "path": "d:\\projects\\gchgz-backend", "trustLevel": "trusted", "suggestion": "建议挂载项目级指令资产" } ]
}
```

**绝不自动写入 `~/.dsh/settings.yaml`**。

## 8. 会话委托

`migrate_codex_sessions` 行为：

1. 只读统计 `sessions/YYYY/MM/DD/rollout-*.jsonl`（数量、总行数、时间范围）；
2. 检测 `import_codex` 工具可用性（`ctx.tools` 中查找）：
   - 可用 → 直接委托（`preview` 时调用其 preview 语义），返回其导入结果摘要；
   - 不可用 → 返回安装指引（`dsh plugin --profile <p> add dsh-chat-import`）。
3. 台账记录委托结果（会话数、来源指纹）。

## 9. 不迁移清单（明示跳过）

| 项 | 原因 | 报告动作 |
| --- | --- | --- |
| `auth.json`、`.codex-global-state.json` | 凭据/设备状态 | `skipped(secret)` |
| `chrome-native-hosts*.json` | 本地桥接含密钥 | `skipped(secret)` |
| `[desktop]` 主题/字体/头像 | DSH 皮肤体系不同 | `skipped(not-applicable)` |
| marketplace/插件本体 | 许可证与分发绑定 | `skipped(not-applicable)` + 功能等价建议 |
| `history.jsonl`、运行时 sqlite（goals/queue/state/thread_history） | 运行时状态，无迁移价值 | `skipped(not-applicable)` |
| 运行时 MCP（node_repl 等） | DSH 自带等价能力 | `skipped(runtime)` |
